# Eternal Polyclinic website

Booking website for Eternal Polyclinic, Opposite SHD Hospital, Sopore.

## Run it on your computer

```bash
npm install     # first time only
npm run dev     # then open http://localhost:3000
```

## Change clinic details

Edit `data/clinic.ts`. Doctors, OPD days, hours, phone and fee are all there.

## Deploy

Push to GitHub. Vercel builds and deploys every push to `main` automatically.
